# Storage policy

This repository is an index. It must stay small.

Allowed: README catalog table, papers/catalog.json, instruction markdown, workflow YAML, license, citation, issue templates, links, badges, DOIs.

Forbidden: manuscript PDFs, raw data, figure folders for individual papers, built packages, copies of child-repo trees.

GitHub Packages, Actions artifacts, and Releases belong on the child, never as duplicates on the hub.
